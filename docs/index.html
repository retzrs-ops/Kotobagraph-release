Kotobagraphコトバグラフ

音声・動画ファイルから、文字起こしを作る Windows 用の無料アプリです。OpenAI の音声認識モデル Whisper を使い、すべてお使いのパソコンの中で処理します。音声データは外部に送信されません。

できること

  • ファイルを選ぶか、ドロップするだけ：音声・動画ファイルをウィンドウに入れると、すぐに文字起こしを始めます
  • モデルを選べる：迷ったときの large-v3-turbo、日本語特化の kotoba-whisper-v2.0、最高精度の large-v3、軽い small
  • GPU で速くなる：NVIDIA（CUDA）に加え、AMD / Intel の GPU（Vulkan）にも対応。GPU が無いパソコンでも、CPU で動きます
  • 自動品質チェック：自信の低い所や、同じ言葉の繰り返しなどの「怪しい所」だけを自動で聞き直し、明らかに良くなったときだけ差し替えます
  • AI・議事録への連携：フィラー（「えー」「あの」など）を取り除いた文章や、議事録用の指示文を付けた文章を、ワンクリックでコピーできます
  • リアルタイム議事録v1.5.0〜：マイクの声をその場で文字起こしし、決定事項・アクション・保留事項などを含む議事録を自動で作ります。録音（MP3）も保存します
  • 自動保存：文字起こしが終わると、音声ファイルと同じ場所にテキストファイルを保存します
  • 進み具合の表示：進み具合と、残りの予想時間を表示します。いつでも中止できます
音声は、お使いのパソコンの中だけで処理します。インターネットを使うのは、初回のモデルや FFmpeg、議事録用 AI のダウンロードのときだけです。

動作環境と保存されるファイル

動作環境

  • Windows 10 / 11（64bit）
  • GPU（なくても動きます）：NVIDIA、または AMD / Intel。最新のグラフィックドライバをおすすめします
  • インターネット接続：初回のモデル、FFmpeg、議事録用 AI のダウンロードのときだけ必要です
  • 空き容量：使うモデルに応じて、約 1〜4 GB（リアルタイム議事録の AI を使うときは、さらに約 2.5 GB）
  • マイク：リアルタイム議事録を使うときに必要です

保存されるファイル・設定

  • models フォルダ：Kotobagraph.exe と同じ場所に作られ、ダウンロードしたモデルが入ります（AMD / Intel の GPU 用は models\ggml）
  • ffmpeg.exe / ffprobe.exe：自動ダウンロードしたとき、Kotobagraph.exe と同じ場所に保存されます
  • models\llm フォルダ / llama_cpp フォルダ：リアルタイム議事録の AI のモデルと実行部品が入ります
  • 議事録 フォルダ：リアルタイム議事録の録音・全文・議事録が、会議ごとのフォルダ（yymmdd_hhmm）で保存されます
  • 初期プロンプトの入力内容：Windows のユーザー設定（レジストリ）に自動で保存されます
  • 文字起こしのテキスト：音声ファイルと同じ場所に、（音声ファイル名）_モデル名.txt として保存されます
アンインストールするときは、フォルダごと削除してください。モデルが入っているので、フォルダは大きくなります。

はじめての設定

  1. zip を展開して、起動するダウンロードした zip を右クリック →「すべて展開」。展開したフォルダの Kotobagraph.exe をダブルクリックします。
    青い警告「WindowsによってPCが保護されました」が出たら、「詳細情報」→「実行」を押してください。電子署名が付いていないための警告です。
  2. FFmpeg を入れる画面の上の「FFmpeg/FFprobeを自動ダウンロード・修復」ボタンを押します。音声を読み取るために必要な ffmpeg.exe と ffprobe.exe が、まとめて入ります（片方だけ足りないときも、同じボタンで直ります）。
  3. モデルを選ぶはじめは、初期値の large-v3-turbo のままで大丈夫です。迷ったときは「モデル比較」ボタンで、各モデルの特徴を見られます。モデルは、はじめて使うときに自動でダウンロードします（約 0.5〜3 GB）。
  4. デバイス（使う部品）を選ぶ
    • NVIDIA の GPU：「NVIDIA GPU 0 (CUDA)」
    • AMD / Intel の GPU：「（GPU の名前） (Vulkan)」
    • GPU が無いとき：「CPU (標準動作)」
    GPU が見つかったときは、はじめから GPU が選ばれています。

文字起こしのしかた

  1. ファイルを入れる次のどちらかです。
    • 「音声/動画ファイルを選択して実行」ボタンを押して、ファイルを選ぶ
    • ウィンドウの中に、音声・動画ファイルをドラッグ＆ドロップする
  2. 待つ進み具合と、残りの予想時間が出ます。やめたいときは「処理中止」ボタンを押します。
  3. 結果を受け取る終わると、かかった時間（所要時間）が出て、音声ファイルと同じ場所にテキストファイル（_モデル名.txt）が自動で保存されます。
AMD / Intel の GPU をはじめて使うときは、GPU 用のモデルを別にダウンロードします（2回目からは不要です）。ダウンロード中も進み具合が出て、中止もできます。

リアルタイム議事録 v1.5.0〜

マイクで拾った声をその場で文字起こしし、会議の議事録を自動で作ります。「リアルタイム議事録」タブを使います。音声も議事録も、お使いのパソコンの中だけで処理します。

  1. 必要なものを用意するはじめて使うときは、足りないものがあると「録音・議事録の作成を開始」ボタンが灰色になり、赤い案内が出ます。「必要なものをダウンロード」ボタンを押すと、次のものがそろいます（初回のみ）。
    • 文字起こしのモデル
    • 議事録を作る AI の実行部品（約 35 MB）
    • 議事録を作る AI のモデル（約 2.5 GB）
  2. 選ぶ文字起こしのモデル、使うデバイス（GPU / CPU）、マイクを選びます。GPU があるときの初期値は large-v3-turbo、CPU だけのときは軽い small です。マイクを選ぶと「マイクの入力レベル」のバーが動くので、声を出して確かめてください。
  3. 開始する緑の「録音・議事録の作成を開始」を押して話します。左に認識した発言、右に議事録が出てきます。状態は色付きの帯に表示されます（「● 録音・議事録作成中」など）。
  4. 終わる赤の「終了して保存」を押します。最後の発言と議事録を仕上げて、保存します。「保存先を開く」で、保存したフォルダを開けます。

議事録に載る項目

  • 基本情報：開催日時（録音の開始と終了から自動）、会議名、開催場所、出席者、欠席者、記録者
  • 議題、議論の要約（発言した人の名前が分かれば付きます）
  • 決定事項
  • アクションプラン：誰が・何を・いつまでに
  • 保留事項・懸念点、次回開催予定
会議名・場所・出席者・担当者・期限などは、会議の中で声に出して言ったものだけが入ります。聞き取れなかった項目は載せません（推測で埋めません）。入れたい情報は、会議の中で言葉にしてください。

文字起こしと議事録が更新されるタイミング

  • 発言は、約 10 秒ごとに文字起こしします。2 秒ほど静かになったときも、そこで区切って文字起こしします
  • 議事録は、約 10 秒ごとに新しい項目を足し、約 1 分ごとに全体を整え直します（新しい発言を優先して、矛盾を直します）
  • AMD / Intel の GPU では、発言ごとにモデルを読み込むため、NVIDIA の GPU より少し遅れが出ます（10 秒の発言で 2 秒ほどが目安）

保存されるファイル

Kotobagraph.exe と同じ場所の 議事録 フォルダに、開始するたびに「yymmdd_hhmm」（例：261024_1430 ＝ 2026年10月24日14時30分）のフォルダを作って保存します。同じ分にもう一度始めたときは「_2」を付けるので、上書きされません。

  • audio.mp3：録音
  • 全文.txt：時刻付きの全文（発言ごとに追記するので、途中で止まっても残ります）
  • 議事録.md / 議事録.json：議事録
「議事録を自動で作る（AI）」のチェックを外すと、議事録は作らず、文字起こしと録音だけを行います。録音中は、ファイルの文字起こしは始められません。

AI・議事録に使う

文字起こしが終わったあと、結果をブラウザ版の AI などに貼り付けて、きれいな文章にできます。

  • AI 整形用テキストをコピー：「えー」「あの」などのフィラーを取り除いた文章を、クリップボードにコピーします
  • 議事録フォーマットでコピー：「概要・決定事項・議論のポイント・TODO」にまとめるための指示文を付けて、クリップボードにコピーします。AI に貼り付けるだけで、議事録の形になります
「初期プロンプト」にキーワードを登録しておくと、コピーする指示文にも付けられ、AI が言葉を直すときの手がかりになります（詳細オプションを見てください）。

モデルの選び方

モデル特徴向いている場面
large-v3-turbo
（初期値）		large-v3 の高速版。精度をほぼ保ったまま数倍速く、句読点も自然迷ったらこれ
kotoba-whisper-v2.0日本語特化。large-v3 の約6倍速く、精度も近い。句読点は少なめ日本語だけの音声を、速く処理したいとき
large-v3最も精度が高い。処理にいちばん時間がかかる雑音が多い音声や、専門用語が多い会話
smallいちばん軽い。精度は大きく下がるほかのモデルが重すぎるパソコン

モデルは、はじめて使うときに自動でダウンロードします（約 0.5〜3 GB）。選んでいるデバイス（GPU / CPU）で使えないモデルは、一覧に出ません。

詳細オプション

「詳細オプション」タブで、必要に応じて調整できます。わからないときは、そのままで大丈夫です。

  • CPU コア数：CPU で動かすときに使う数（スレッド数）を選べます。増やすと速くなりますが、ほかの作業が重くなります
  • 初期プロンプト：会議で使う専門用語や名前を登録しておくと、聞き取りの精度が上がります。入力した内容は自動で保存されます
  • VAD フィルター：音声のある所を自動で見つけて、無音をとばします。処理が速くなります
  • 無音自動カット：指定した秒数（0.2〜5.0 秒）以上続く無音を、先に取り除きます。処理時間を短くできます
  • 高速探索モード：さらに処理を速くする切り替えです

GPU で速くする

お使いの GPU選ぶものメモ
NVIDIANVIDIA GPU 0 (CUDA)自動で見つけて、高速な CUDA で動かします
AMD / Intel（GPU の名前） (Vulkan)追加のインストールは不要で、グラフィックドライバだけで動きます。はじめて使うときに、GPU 用モデルをダウンロードします
GPU なしCPU (標準動作)どのパソコンでも動きますが、時間がかかります

自動品質チェック（聞き直し）も、GPU で動きます。怪しい所をまとめて一度に処理するので、速く終わります。

困ったとき

「ffmpeg」のエラーが出る・音声が読み込めない

画面の上の「FFmpeg/FFprobeを自動ダウンロード・修復」ボタンを押してください。ffmpeg.exe と ffprobe.exe が足りないか、こわれている可能性があります。インターネットにつながっているか、確かめてください。

AMD / Intel の GPU が選べない

グラフィックドライバを最新にしてください。それでも出ないときは、「CPU (標準動作)」を選べば使えます。

処理が遅い
  • デバイスが「CPU」になっていないか、確かめてください（GPU があるパソコンのとき）
  • モデルを large-v3-turbo か kotoba-whisper-v2.0 にすると、速くなります
  • 「詳細オプション」で、VAD フィルターや無音自動カットを使うと、短くなることがあります
同じ言葉がくり返される・おかしな文字が出る

音声に雑音や無音が多いと起きやすい症状です。自動品質チェック（再推論）が直すことがありますが、直らないときは、large-v3 を試すか、「無音自動カット」を使ってください。

専門用語や名前を間違えて書かれる

「詳細オプション」の「初期プロンプト」に、その言葉を登録してください。聞き取りの精度が上がります。

リアルタイム議事録の開始ボタンが灰色で押せない

赤い案内に「足りないもの」が出ています。「必要なものをダウンロード」ボタンを押してください。インターネットにつながっている必要があります。

マイクの入力レベルのバーが動かない・発言が出てこない
  • 「マイク」の選択が合っているか確かめてください。声を出したとき、バーが右へ伸びれば、そのマイクは使えています
  • バーがほとんど動かないときは、パソコンのサウンド設定でマイクの音量が小さくなっていないか、確かめてください
  • 「マイクを開けません」と出るときは、ほかのソフトがそのマイクを使っていないか、確かめてください
リアルタイム議事録の文字起こしが遅れる・精度が低い
  • GPU があるときは、デバイスで GPU を選んでください。精度は large-v3-turbo が高めです
  • CPU だけで追いつかないときは、small にすると軽くなりますが、精度は下がります
  • 会議の名前や専門用語は、「詳細オプション」の初期プロンプトに登録すると、聞き取りの手がかりになります
青い警告「WindowsによってPCが保護されました」が出る

「詳細情報」→「実行」で起動できます。電子署名が付いていないための警告です。
